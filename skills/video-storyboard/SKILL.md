# 영상 콘티와 샷 설계

현재 대본이나 화면·음성 기획을 다른 제작자가 실행할 수 있는 샷으로 옮긴다. 텍스트 표만으로도 완성할 수 있다. 핵심은 샷마다 관객이 무엇을 보거나 알게 되는지, 어떤 상태로 시작해 어떻게 끝나는지 명확히 하는 것이다.

## 범위와 입력

- 기존 대본, 채택한 기획, 실제 참고 자료와 사용자가 정한 길이·화면비·제작 방식을 재사용한다. 파일을 기준으로 수정하는 요청이면 과거 대화의 초안 대신 현재 파일을 읽는다.
- 이야기·인물·대사를 새로 만드는 단계는 해당 극작 스킬이나 영상 기획의 범위다. 콘티를 만들면서 원문의 사건·주장·공개 순서를 몰래 바꾸지 않는다. 필요한 생략·재배치는 해당 샷에 이유를 남긴다.
- 촬영, 화면녹화, 자료화면, 그래픽, 생성형 영상은 한 작품 안에 섞을 수 있다. 제작 방법이 정해지지 않은 부분은 실행 가능한 제안으로 표시하고 독립적으로 완성 가능한 샷은 계속 작성한다.
- 공급자별 길이·참조 이미지·입출력 제한은 실제 대상이 정해졌을 때만 현재 사양을 확인한다. 특정 모델, JSON, 폴더명이나 이미지 생성을 콘티의 선행 조건으로 만들지 않는다.

## 반복 등장하는 인물과 공간

여러 샷에서 같은 인물·장소·사물이 등장하면 샷 작성 전에 기존 설정·참조에서 공통 기준을 정한다. 한 번 나오는 작은 사물까지 자료집으로 만들거나 짧은 요청에 별도 문서를 강제하지 않는다. 필요한 표와 예시는 [기준 자료와 상태 변화](references/shot-design.md#기준-자료와-상태-변화)에 있다.

- 인물의 얼굴·체형·식별 특징, 장소의 지형·출입구·주요 사물 배치를 기준 자료에 연결한다. 필요한 각도의 이미지만 사용하고 서로 같은 인물·공간인지 먼저 대조한다. 의상·빛·날씨는 해당 장면의 조건으로 정하며 의도된 변화를 금지하지 않는다.
- 고정 정보와 바뀌는 상태를 나눈다. 샷에는 기준 자료를 참조하고, 인물 위치·시선·쥔 손·소품 소유·열림·파손 등 이번 샷에서 필요한 시작→변화→끝을 적는다. 시간 순서로 이어지는 다음 샷은 앞 샷의 끝 상태를 받는다.
- 일관성은 같은 구도의 반복이 아니다. 실제 공간의 기준점, 인물 신체의 좌우, 화면 좌우를 구별하고 카메라 방향이 달라져도 공간 관계가 성립하게 한다.
- 생성형 영상의 제작 지시는 같은 기준 자료로 샷별 정지 구도를 맞춘 뒤 영상화하도록 구성한다. 이전 결과의 끝 프레임을 쓰더라도 원래 인물·공간 기준을 함께 대조하며, 임의로 달라진 디테일을 다음 샷의 새 설정으로 굳히지 않는다.
- 반복 장소의 정확한 거리·가림·동선이 중요한 경우에만 평면도나 간단한 3D 배치·카메라를 제작 방법으로 제안한다. 단순 대화 장면에 3D 작업을 필수화하지 않는다. 구체적 선택은 [공간 배치와 영상화 전달](references/shot-design.md#공간-배치와-영상화-전달)을 따른다.

## 샷으로 옮기기

1. 원문의 핵심 동작·대사·설명·화면 글자를 어느 화면과 소리가 담당할지 정한다. 한 문장에 한 샷을 강제하지 않는다. 관객이 새 정보, 반응, 공간 관계를 읽어야 하는 곳에서 나누고 같은 정보를 반복하는 샷은 합친다.
2. 샷 목적을 먼저 쓰고 구도와 카메라를 고른다. “인물 중경”보다 “거절을 들은 사람이 서명을 멈추는 것을 보여준다”처럼 무엇을 읽어야 하는지 적는다. 정지 화면과 고정 카메라도 목적에 맞으면 충분하다.
3. 샷마다 안정적인 ID, 원문 위치, 예상 길이, 화면·구도, 피사체 동작, 카메라 동작, 시작→끝 상태, 음성과 필요한 자료를 작성한다. 간단한 영상에서는 관련 칸을 합치고 불필요한 필드는 생략한다. 상세 틀은 [샷 템플릿과 연속성](references/shot-design.md)을 사용한다.
4. 말하기·읽기·동작이 실제로 가능한 시간을 배정한다. 녹음이 있으면 그 길이를 기준으로 삼고, 없으면 낭독·동작 시간을 추정값으로 표시한다. 음성과 동시에 가능한 동작은 중복 합산하지 않으며, 필요한 멈춤과 반응은 확보한다. 고정 컷 수·평균 초수로 내용량을 밀어 넣지 않는다.
5. 연속 장면은 공간의 고정 기준점, 인물 위치·시선, 화면 진행 방향과 소품 상태를 이어 쓴다. 시간 생략, 반복, 회상, 몽타주는 의도임을 표시한다. 원문에 “후반에 처음 공개” 같은 조건이 있으면 전체 길이에 맞는 시간 경계로 옮긴다.

샷의 시작에는 아직 일어나지 않은 결과를 넣지 않는다. 예를 들어 시작이 ‘빈손으로 봉투를 본다’이면, 봉투를 집는 과정과 마지막에 쥔 손이 연결되어야 한다. 다음 샷은 ‘이미 쥔 상태’에서 이어지며 같은 집기 동작을 우연히 반복하지 않는다.

## 제작 방식별 전달

- **촬영:** 최종 영상의 샷 ID를 유지한 채 장소·세팅·출연자 기준으로 촬영 순서를 묶을 수 있다. 이야기 순서와 촬영 순서를 구분하고 바뀌는 의상·소품·시간대를 표시한다. 촬영 효율 때문에 필요한 반응이나 연결 동작을 없애지 않는다.
- **자료화면:** 단순 장식인지 실제 주장의 근거인지 구분한다. 필요한 화면의 내용, 원출처·구간, 확보 상태를 적는다. 검색어 또는 후보 링크만 있는 것을 확보한 파일로 표시하지 않는다. 재연·생성 화면이 실제 사건의 기록으로 오인되지 않게 표현 방식을 정한다.
- **화면녹화·설명 그래픽:** 관객이 찾아야 할 UI·수치·변화를 정하고 시작 화면→조작→결과를 쓴다. 확대·강조 위치와 읽을 시간을 확보한다. 실제 서비스에 없는 기능이나 결과를 사실처럼 꾸미지 않는다. 정확한 글자는 원문과 연결하고 후편집 합성 여부를 적는다.
- **생성형 영상:** 요청된 범위에서 시작 키프레임과 모션 브리프를 분리해 작성한다. 키프레임은 한 순간의 위치·자세·시선·손·소품·빛·구도만, 모션은 행동 순서·카메라 이동·대사 시점·끝 상태를 담는다. 끝 키프레임은 필요한 제작 방식에서만 추가한다. 필수 중간 동작을 시작·끝 이미지 사이의 자동 보간에만 맡기지 않는다.

실제 참조 이미지는 열어 확인한 파일만 연결하고 무엇을 고정하는지 명시한다. 인물 정체성, 의상, 장소, 구도, 스타일은 서로 다른 역할이다. 없는 이미지는 ‘준비 예정’으로 남기고 프롬프트를 파일로 취급하지 않는다. 독립 전달용 프롬프트는 ‘앞 샷과 같음’ 대신 그 프레임에 필요한 상태를 직접 쓴다.

## 완료와 수정

요청된 구간의 내용이 화면·소리로 전달되고, 샷 길이가 내용을 감당하며, 인접 샷의 동작·공간·소품이 연결되면 콘티가 완성된다. 확인에 필요한 사항은 기존 콘티 안에서 고치고 별도 검토 보고서나 승인 단계를 만들지 않는다. 아직 없는 자료와 예상 길이만 짧게 구분해 알린다.

수정 시 영향받지 않은 샷 ID를 보존한다. 분할·병합 시 대응 관계와 갱신이 필요한 촬영·편집·생성 지시만 표시한다. 기준 자료를 바꾸면 영향을 받는 샷의 참조와 상태만 갱신한다. 이 스킬의 산출물은 콘티와 제작 지시이며, 적용 자체가 이미지·영상 생성, 유료 API 호출, 촬영, 외부 게시의 승인을 뜻하지 않는다. 콘티만 요청받았으면 이미지 생성이나 렌더 검사를 완료 조건으로 추가하지 않는다.
