# AV 대본과 제작 전달

제작용 대본이나 여러 소스가 섞인 영상의 전달 구조가 필요할 때 사용한다. 아래 표를 전부 채우는 절차가 아니라 작업에 맞는 열만 선택하는 예시다.

## 짧은 제작안

- 목표·대상: 누가 무엇을 이해하거나 경험해야 하는가.
- 핵심: 영상이 끝나도 남아야 할 한 가지.
- 형식·길이: 확정된 규격과 실측 또는 예상 길이.
- 구성: 내용이 전개되는 순서와 주요 화면.
- 제작 조건: 확보된 자산과 실제 진행을 막는 미확보 항목.

## AV 대본 예시

다음은 파일 정리 기능을 설명하는 가상 튜토리얼이다. 제품의 실제 기능이나 측정 결과를 뜻하지 않는다. 구간 길이는 녹음·시연 후 채우며, 처음부터 가짜 타임코드를 정밀하게 만들지 않는다.

| 구간 ID | 음성·소리 | 화면·행동 | 소스·확보 상태 |
|---|---|---|---|
| A | [내레이션] “먼저 정리할 폴더를 선택합니다.” | 폴더 선택부터 목록 표시까지 실제 조작. 필요한 버튼 이름만 강조 | 화면 녹화 필요. 개인정보 없는 예제 폴더 사용 |
| B | [내레이션] “이름이 같아도 내용이 다르면 남겨 둡니다.” | 다른 내용의 파일 두 개를 비교. 실제 동작을 확인할 수 없으면 설명용 도표로 구분 | 기능 근거·조작 가능 여부 미확인 |
| C | [무음 시연] 결과를 읽을 시간 | 실제 결과 목록에서 유지·제거 대상이 구분되는 부분 유지 | A와 같은 녹화에서 확보 예정 |

무음이나 음악만 있는 영상은 음성 열에 그 상태를 명시한다. 음성과 겹치는 행동과 음성이 멈춘 뒤 이어지는 시연을 구분해야 총길이가 부풀지 않는다. 효과음·음악은 전달에 필요한 경우에만 제안한다.

## 분량 산정 메모

- `실측`: 선택한 목소리·속도로 만든 음성 또는 실제 낭독을 측정했다는 뜻. 음성이 없는 상태에서 붙이지 않는다.
- `예상`: 대표 문단의 실측을 전체에 적용하거나 제작 전 추정한 값. 산정 근거와 큰 오차 요인만 기록한다.
- 예상보다 길면 반복 정보와 불필요한 도입부터 조정한다. 배속을 높여 읽기·이해 시간을 희생하는 것을 기본 해결책으로 삼지 않는다.
- 음성·시연·자막이 동시에 진행되는 구간은 가장 오래 걸리는 요소가 구간 길이를 결정할 수 있다. 이들을 단순 합산하지 않는다.

## 소스와 촬영 전달

| 컷·소스 ID | 연결 구간 | 얻어야 할 화면 | 위치·원본 | 준비·제약 |
|---|---|---|---|---|
| REC-01 | A, C | 폴더 선택과 결과 목록의 실제 변화 | 녹화 예정 | 예제 데이터와 재현 가능한 상태 필요 |
| GRAPH-01 | B | 동일 이름·서로 다른 내용의 비교 원리 | 편집용 도표 예정 | 확인된 기능 설명에 맞춰 내용 확정 |

실제 촬영이 여러 세팅에 걸치면 같은 장소·조명·출연 준비를 묶어 촬영할 수 있다. 각 컷의 대본 구간 ID는 유지해 편집 순서를 복원한다. 확보한 테이크를 보지 않았으면 사용 가능하다고 판정하지 않는다.
