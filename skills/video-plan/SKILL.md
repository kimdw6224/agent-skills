# 영상 기획

아이디어를 듣는 내용과 보는 내용이 함께 정해진 제작안으로 구체화한다. 계획의 상세도는 사용자가 결정해야 하는 문제에 맞춘다. 짧은 영상 아이디어 요청에는 핵심 방향과 구성으로 답하고, 제작용 요청에는 AV 대본과 필요한 자료·촬영 목록까지 작성한다.

## 현재 맥락에서 시작

- 제공된 대본, 채널 성격, 기존 제작 규칙, 승인된 사실과 소재를 재사용한다. 이미 정한 툴·화면비·목소리·제작 방식을 다른 방식으로 임의 교체하지 않는다.
- 영상의 목표, 보는 사람과 사전 지식, 핵심 메시지, 게시 형식과 목표 길이, 사용할 수 있는 소스·촬영 조건을 파악한다. 전부를 설문처럼 묻지 않고, 결과를 크게 바꾸며 추론할 수 없는 입력만 질문한다.
- 정보 전달, 감정 경험, 사용법 이해, 행동 유도 등 이번 영상이 실제로 달성해야 할 목적을 기준으로 구성한다. 모든 영상에 광고형 도입, CTA, 반전, 반복 재생 결말을 넣지 않는다.
- 사용자가 요청한 산출물을 먼저 완성한다. 여러 대안을 요청하지 않았으면 근거가 있는 방향 하나로 진행하고 중요한 가정만 밝힌다.

## 정보와 구성

1. 시청 후 남아야 할 핵심을 한 문장으로 잡고, 이를 이해하는 데 필요한 내용과 있으면 좋은 내용을 구분한다. 정보 나열보다 질문→설명, 과정→결과, 상황→변화 등 소재에 맞는 흐름을 선택한다.
2. 사실 영상은 주장과 그 근거가 어느 화면·대사에서 쓰이는지 연결한다. 제공되지 않은 수치, 실사용 결과, 인용, 촬영 사실을 만들어 넣지 않는다. 미확인 항목은 표시하고, 핵심 판단에 필요한 새 조사만 수행한다. 자료조사가 주된 작업이면 사용 가능한 `research-brief`를 활용할 수 있다.
3. 드라마·다큐의 서사나 인물·대사가 핵심이면 기존 극작 스킬에서 이미 만든 내용을 재사용한다. 영상 기획을 이유로 매번 조사·극작·검증 스킬을 연쇄 실행하지 않는다.
4. 중복 설명부터 덜고, 이해에 필요한 조건·반례·인과를 보존한다. 지정 길이 안에 핵심이 들어가지 않으면 내용을 줄이거나 편수를 나누는 선택을 제안하되 확정된 분량을 몰래 바꾸지 않는다.

## 음성과 화면을 함께 설계

제작용 구성에는 구간별로 **들리는 것 | 보이는 것**을 짝지어 쓴다. 대사·내레이션·침묵·효과음과 화면 행동·자료·자막의 관계를 명확히 한다. 필요한 표 형식과 전달 예시는 [AV 대본과 제작 전달](references/av-and-handoff.md)을 참고한다.

- 화면은 설명을 증명하거나 이해를 돕거나 정서를 형성하는 역할을 갖게 한다. “관련 영상”, “역동적인 장면” 대신 필요한 대상·행동·정보를 특정한다.
- 화면 속 글과 내레이션이 같은 정보를 반복하는지 판단한다. 반복이 학습·접근성에 도움이 되면 유지하고, 동시에 읽고 들어야 할 서로 다른 정보는 줄인다.
- 인터뷰나 낭독에서 한 화면을 유지하는 선택도 유효하다. 일정 초마다 컷을 바꾸거나 말하는 얼굴을 무조건 자료화면으로 덮지 않는다.
- 각 소스가 **직접 촬영 / 화면 녹화 / 기존 자료 / 생성 자산 / 편집으로 만드는 도표·텍스트** 중 무엇인지 구분한다. 실제 확보된 파일과 확보 예정 자료를 혼동하지 않는다.
- 사실 영상의 생성·재연 화면을 사건의 실제 기록처럼 제시하지 않는다. 자료 출처와 사용 조건이 필요한 항목은 소스와 함께 남긴다. 상세 구도·동선·연속성 설계가 필요할 때 `video-storyboard`로 구체화할 수 있다.

## 한국어 분량과 실현 가능성

- 우선 실제 한국어 낭독이나 선택된 TTS의 음성 길이를 사용한다. 이미 음성이 있으면 파일의 실제 길이와 쉼을 기준으로 화면을 배치한다.
- 실측이 없으면 `예상`으로 표시한다. 대표 문단의 실제 발화 속도로 추정할 수 있지만, 영어 단어 수 기준을 한국어에 그대로 적용하거나 추정치를 측정값처럼 보고하지 않는다.
- 전체 길이는 발화·무음·동작·읽기 시간을 타임라인으로 계산한다. 내레이션과 겹치는 자료화면 시간을 따로 더하지 않고, 설명이 끝난 뒤 필요한 독립 시연·침묵만 추가한다. 도표·자막을 알아볼 시간도 고려한다.
- 길이 확인만을 위해 미승인 유료 생성·다운로드를 시작하지 않는다. 확보된 음성이나 사용자가 허용한 제작 수단을 활용한다.
- 필요한 인물·장소·장비·자료가 실제로 가능한지 구성과 대조한다. 확보가 불확실한 핵심 장면에는 같은 정보를 전달할 수 있는 대안을 제시한다.

## 제작에 넘길 만큼만 정리

- 촬영이 있으면 필요한 컷에 식별자를 붙이고 내용, 음성 대응, 장소·소품·출연자와 필수 여부를 정리한다. 여러 영상이나 장소가 있을 때만 같은 세팅을 묶은 촬영 순서를 추가한다. 편집 순서와 촬영 순서는 구분한다.
- 편집자가 대본 구간을 원본 파일·URL·촬영 컷과 연결할 수 있게 한다. 특정 폴더 체계나 파일명 규칙을 새로 강제하지 않고 프로젝트의 기존 방식을 따른다.
- 결과에는 요청한 기획·대본, 분량의 측정/추정 상태, 진행을 막는 미확보 자료만 남긴다. 작은 작업에 별도 콘티·보고서·체크리스트 파일을 일괄 생성하지 않는다.
- 기획 완성과 실제 촬영·녹음·생성·렌더링 완료를 구분한다. 제작 요청이 이어지면 기존 승인 범위와 도구에 따라 진행하며, 이 기획 자체가 게시·발송이나 유료 도구 사용 승인은 아니다.
